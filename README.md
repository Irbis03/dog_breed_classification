## Постановка задачи

Задача – на основе изображения предсказывать породу собаки.
Делается для получения навыков в пакетировании и распространения экспериментов в ml промышленным способом

## Формат входных и выходных данных

На вход подаётся изображение собаки (в форматах jpeg, png), на выходе — название породы в текстовом виде вместе с вероятностью предсказания.

## Метрики

Метрика, используемая в данной модели: **Accuracy**.

## Валидация

Для валидации набор данных делится в стандартном соотношении, для обеспечения воспроизводимости экспериментов зафиксирован фиксированный seed.

## Данные

Датасет содержит изображения различных пород собак. Для этапов тренировки, валидации и тестирования данные разделены на соответствующие выборки.

## Моделирование

### Бейзлайн

В качестве простого решения используется предобученная сверточная нейросеть в режиме извлечения признаков (feature extractor), поверх которой обучается классификатор.

### Основная модель

Модель основана на фреймворке **PyTorch Lightning** с использованием современных архитектур для компьютерного зрения. Пайплайн включает экспорт весов в формат **ONNX** и оптимизацию под железо с помощью **TensorRT** (`trtexec`, поддержка `--fp16`) для ускорения инференса.

## Внедрение

Инференс модели организован в виде готового REST API сервиса с помощью **MLflow Serving** (`mlflow models serve`), что позволяет поднимать модель как микросервис рядом с основным приложением. Для трекинга экспериментов и управления артефактами используется локальный сервер MLflow в связке с `mlflow.db`.

## Setup (Установка и настройка)

Для развертывания проекта и подготовки окружения выполните следующие шаги:

1. **Клонируйте репозиторий и перейдите в него:**

```bash
git clone
cd DogBreedClassification

```

2. **Создайте и активируйте виртуальное окружение:**

```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или venv\Scripts\activate для Windows

```

3. **Установите зависимости:**

```bash
pip install --upgrade pip
pip install -r requirements.txt

```

_(Или используйте менеджера зависимостей проекта, если настроен `pyproject.toml` / Poetry)._ 4. **Инициализация окружения MLflow:**
Проект настроен на локальное сохранение метаданных в SQLite и артефактов в директорию `mlartifacts/`. Никаких дополнительных внешних подключений к S3/Google Drive не требуется.

## Train (Обучение модели)

Процесс обучения управляется скриптом `train.py` и интегрирован с трекингом MLflow. Для удобства отладки и быстрого прогона предусмотрены специальные флаги (например, ограничение батчей).

1. **Запуск полного цикла обучения:**

```bash
python train.py

```

_Скрипт автоматически инициализирует сессию в локальной базе данных `mlflow.db`, запустит обучение модели на базе PyTorch Lightning, сохранит лучшие чекпоинты (включая `tmp/checkpoints/best`) и залогирует артефакты в `mlartifacts/`._ 2. **Быстрая отладка и тестовый прогон:**
Если вам нужно быстро проверить работоспособность пайплайна без ожидания полного обучения эпох, вы можете использовать встроенные ограничения батчей (или быстрый режим дебага):

```bash
python train.py --fast_dev_run=True

```

_(Либо ограничить количество шагов обучения через конфигурационные параметры)._ 3. **Мониторинг процесса:**
Для визуального контроля за метриками и параметрами заложите локальный сервер MLflow UI:

```bash
mlflow server --backend-store-uri sqlite:///mlflow.db --default-artifact-root ./mlartifacts --port 5000

```

После этого откройте в браузере `[http://127.0.0.1:5000](http://127.0.0.1:5000)`.
