# Dog Breed Identification — MLOps Project

Классификация пород собак по фотографиям с использованием PyTorch Lightning, Hydra, DVC и MLflow.

## 📌 Описание проекта

Данный проект решает задачу классификации 120 пород собак по изображениям. В качестве основы используется сверточная нейросеть ResNet18 с трансферным обучением. Проект полностью пакетирован и соответствует принципам воспроизводимости ML-экспериментов.

## 📁 Структура проекта

```text
.
├── configs/          # Конфигурации Hydra (data, model, trainer)
├── plots/            # Сохраненные графики обучения
├── src/
│   └── dog_breed/    # Модули пакета (data, models, utils, train, infer)
├── tests/            # PyTest тесты
├── pyproject.toml    # Конфигурация зависимости и пакета
└── README.md
```
